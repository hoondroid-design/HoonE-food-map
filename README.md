# 강릉 뭐먹지 — 완전 초보자용 런칭 가이드

> GitHub도 처음, 개발도 처음이신 분을 위한 가이드입니다. 순서대로, 빠짐없이 따라오시면 끝까지 완성됩니다.
> 중간에 막히면 그 단계 번호를 알려주시면 더 구체적으로 도와드릴 수 있어요.

## 전체 순서 (체크리스트)

- [ ] 0단계. 필요한 것 미리 준비하기
- [ ] 1단계. GitHub 계정 만들기
- [ ] 2단계. GitHub에 저장소(내 사이트가 저장될 공간) 만들기
- [ ] 3단계. 파일 6개 업로드하기
- [ ] 4단계. GitHub Pages 켜서 사이트 주소 받기 (1차 확인 — 지도 없이 뜨는지)
- [ ] 5단계. 카카오맵 API 키 발급받기
- [ ] 6단계. GitHub에서 파일 직접 수정하기 (카카오 키 넣기)
- [ ] 7단계. 구글시트 공유 설정하기
- [ ] 8단계. 클릭수 자동 기록 설정하기 (Apps Script)
- [ ] 9단계. 방문자수/조회수 설정하기 (GA4)
- [ ] 10단계. 최종 점검

---

## 0단계. 필요한 것 미리 준비하기

- 구글 계정 (이미 시트를 만드셨으니 있으실 거예요)
- 이메일 주소 하나 (GitHub 가입용, 구글 계정 이메일 그대로 써도 됩니다)
- PC 브라우저 (크롬 추천). 스마트폰으로도 가능하지만 처음엔 PC를 권장합니다.

이 대화에서 첨부해드린 6개 파일을 미리 다운로드해서 PC의 아무 폴더(예: 바탕화면에 "강릉맛집" 폴더)에 모아두세요.
- index.html
- style.css
- app.js
- config.js
- apps-script.gs
- README.md (지금 이 파일)

## 1단계. GitHub 계정 만들기

1. 브라우저에서 **github.com** 접속
2. 오른쪽 위 **Sign up** 버튼 클릭
3. 이메일 주소 입력 → **Continue**
4. 비밀번호 만들기 → **Continue**
5. 사용자 이름(username) 만들기
   - 이게 앞으로 내 사이트 주소에 그대로 들어갑니다. 예: `hoond123` 으로 만들면 사이트 주소가 `hoond123.github.io/...` 형태가 돼요.
   - 영어 소문자, 숫자만 가능합니다.
6. 자동으로 뜨는 퍼즐(로봇이 아님을 확인하는 절차) 풀기
7. 이메일로 인증 코드가 옵니다. 메일함 확인 후 코드 8자리를 입력
8. 가입 완료되면 몇 가지 설문(선택)이 나오는데, 다 **Skip** 눌러도 됩니다.

이제 GitHub 로그인이 된 상태로 다음 단계로 넘어갑니다.

## 2단계. GitHub에 저장소(Repository) 만들기

"저장소"는 내 사이트 파일들을 담아두는 폴더라고 생각하시면 됩니다.

1. 로그인 후 오른쪽 위 **+** 아이콘 클릭 → **New repository** 클릭
2. **Repository name**에 영어로 이름 입력 (예: `gangneung-food-map`)
   - 띄어쓰기 없이, 영어/숫자/하이픈(-)만 사용
3. **Public** 선택되어 있는지 확인 (기본값이 Public이라 그대로 두면 됩니다)
4. 밑에 "Add a README file" 체크박스는 **체크하지 마세요** (파일을 우리가 직접 올릴 거예요)
5. 맨 아래 초록색 **Create repository** 버튼 클릭

저장소가 생성되면 빈 폴더 화면이 뜹니다. 주소창에 아래처럼 보일 거예요:
```
github.com/내아이디/gangneung-food-map
```
이 주소를 기억해두세요.

---

## 3단계. 파일 6개 업로드하기

1. 방금 만든 저장소 페이지에서 **Add file** 버튼 클릭 (화면 오른쪽 위쪽에 있음) → **Upload files** 선택
2. 화면 가운데 점선 박스에 PC에 모아둔 6개 파일을 한 번에 **드래그해서 끌어다 놓기**
   - 또는 "choose your files" 글자를 클릭해서 파일 선택창으로 6개 모두 선택
3. 파일들이 목록에 뜨는지 확인 (6개 다 있어야 함)
4. 아래로 스크롤 → **Commit changes** 초록 버튼 클릭
   - 커밋 메시지(설명글) 칸은 그냥 기본값 두고 눌러도 됩니다

업로드가 끝나면 저장소 메인 화면에 6개 파일이 보여야 합니다.

## 4단계. GitHub Pages 켜서 사이트 주소 받기

1. 저장소 페이지 상단 메뉴에서 **Settings** 클릭 (톱니바퀴 아이콘, 메뉴 오른쪽 끝쪽에 있음)
2. 왼쪽 세로 메뉴에서 아래로 스크롤 → **Pages** 클릭
3. **Build and deployment** 항목에서:
   - Source: **Deploy from a branch** 선택 (보통 기본값)
   - Branch: **main** 선택, 옆 폴더는 **/ (root)** 선택
   - **Save** 버튼 클릭
4. 저장 후 1~2분 정도 기다렸다가 같은 페이지를 새로고침
5. 화면 위쪽에 초록색 박스로 다음과 같은 문구와 주소가 뜹니다:
   > Your site is live at `https://내아이디.github.io/gangneung-food-map/`
6. 이 주소를 클릭해서 접속해보세요.

**이 시점에서는 지도가 회색으로 비어있거나 안 뜨는 게 정상입니다.** (아직 카카오 키를 안 넣었으니까요) 페이지 틀과 글자가 나오는지만 먼저 확인하시면 됩니다.

> 사이트 주소를 꼭 메모해두세요. 앞으로 5, 9단계에서 이 주소를 계속 사용합니다.

## 5단계. 카카오맵 API 키 발급받기

1. **developers.kakao.com** 접속
2. 오른쪽 위 **로그인** → 카카오 계정으로 로그인 (카카오톡 쓰시는 그 계정)
3. 처음 로그인하면 개발자 등록 동의 화면이 뜰 수 있음 → 동의하고 진행
4. 상단 메뉴 **내 애플리케이션** 클릭
5. **애플리케이션 추가하기** 클릭
6. 앱 이름: `강릉뭐먹지` (아무 이름이나 가능), 사업자명: 개인 이름이나 아무거나 입력 → **저장**
7. 생성된 앱 아이콘(또는 카드) 클릭해서 들어가기
8. 왼쪽 메뉴 **앱 키** 클릭
9. **JavaScript 키** 부분의 문자열을 복사 (긴 영문+숫자 조합, 예: `a1b2c3...`)
   - 메모장 등에 잠깐 붙여넣어 보관해두세요
10. 왼쪽 메뉴 **플랫폼** 클릭
11. **Web 플랫폼 등록** 클릭
12. 사이트 도메인 칸에 4단계에서 받은 내 사이트 주소를 입력
    - 예: `https://내아이디.github.io`
    - 맨 끝에 저장소 이름이나 슬래시(/)는 빼고, `https://내아이디.github.io` 까지만 입력
13. **저장** 클릭

이제 JavaScript 키를 하나 갖고 계실 거예요. 다음 단계에서 이 키를 사이트 파일에 넣습니다.

## 6단계. GitHub에서 파일 직접 수정하기

컴퓨터에 아무것도 설치할 필요 없이, GitHub 웹사이트에서 바로 파일 내용을 고칠 수 있어요.

### 6-1. index.html 수정 (카카오 키 넣기)

1. GitHub 저장소 페이지로 돌아가기
2. 파일 목록에서 **index.html** 클릭 (파일 내용이 보임)
3. 오른쪽 위 **연필 모양 아이콘** (Edit this file) 클릭
4. `Ctrl+F` (맥은 `Cmd+F`)로 편집 화면 안에서 `KAKAO_APP_KEY` 검색
   - 아래와 같은 줄이 보일 거예요:
     ```
     <script src="//dapi.kakao.com/v2/maps/sdk.js?appkey=KAKAO_APP_KEY&libraries=services"></script>
     ```
5. `KAKAO_APP_KEY` 부분만 마우스로 드래그해서 선택 → 5단계에서 복사해둔 JavaScript 키를 붙여넣기
   - 예: `appkey=a1b2c3...&libraries=services` 형태가 되어야 함
6. 오른쪽 위 **Commit changes** 클릭 → 팝업에서 다시 한 번 **Commit changes** 클릭

### 6-2. config.js 수정 (구글시트 연결 확인)

1. 저장소 파일 목록에서 **config.js** 클릭 → 연필 아이콘 클릭
2. `SHEET_ID` 값이 이미 제공해주신 시트로 맞춰져 있는지 확인 (그대로 두면 됩니다)
3. `SHEET_NAME: "시트1"` 부분을 확인하세요.
   - 본인 구글시트 하단에 있는 **탭 이름**을 확인해서 다르면 여기 이름을 그 탭 이름으로 바꿔주세요.
   - (예: 시트 하단 탭이 "강릉뭐먹지"라고 되어 있으면 `SHEET_NAME: "강릉뭐먹지"` 로 수정)
4. 지금은 `CLICK_LOG_URL` 은 그대로 두세요. **8단계**에서 다시 돌아와 수정합니다.
5. **Commit changes** 클릭

여기까지 하고 사이트 주소를 새로고침하면, 지도와 목록이 나오기 시작해야 합니다. (마커는 하나씩 순차적으로 찍혀서 몇 초 걸릴 수 있어요)

## 7단계. 구글시트 공유 설정하기

이 사이트는 시트의 데이터를 실시간으로 읽어옵니다. 그러려면 "링크가 있는 사람은 볼 수 있게" 권한을 열어줘야 해요.

1. 원본 구글시트 열기
2. 오른쪽 위 파란색 **공유** 버튼 클릭
3. 팝업에서 **일반 액세스** 부분 클릭 (보통 "제한됨"이라고 되어있음)
4. **링크가 있는 모든 사용자**로 변경
5. 오른쪽 역할이 **뷰어**로 되어 있는지 확인 (편집자 아님, 뷰어=읽기전용이어야 안전)
6. **완료** 클릭

이 설정을 하지 않으면 사이트에 데이터가 하나도 안 뜹니다. (가장 흔한 실수 2위)

## 8단계. 클릭수 자동 기록 설정하기 (Apps Script)

식당별로 몇 번 클릭됐는지, 나만 보고 싶다고 하셨죠. 아래처럼 하면 별도 로그인 화면 없이 시트 안에서 바로 확인할 수 있어요.

1. 구글시트 상단 메뉴에서 **확장 프로그램** 클릭 → **Apps Script** 클릭
2. 새 탭에 코드 편집기가 열립니다. 기본으로 `function myFunction() {}` 같은 텍스트가 있을 텐데, 전체 선택(Ctrl+A) 후 삭제
3. 첨부해드린 **apps-script.gs** 파일을 메모장 등으로 열어서 내용 전체 복사 → 방금 지운 자리에 붙여넣기
4. 왼쪽 위 **디스크 모양(저장) 아이콘** 클릭해서 저장
5. 오른쪽 위 **배포** 버튼 클릭 → **새 배포** 클릭
6. "유형 선택" 옆 **톱니바퀴 아이콘** 클릭 → **웹앱** 선택
7. 아래 항목 설정:
   - 설명: 아무 글자나 (예: click-logger)
   - 다음 사용자 권한으로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
8. **배포** 클릭
9. "승인 필요" 화면이 뜨면 → 본인 구글 계정 선택 → "이 앱은 Google에서 확인하지 않았습니다" 라는 경고가 뜰 수 있음
   - 이건 본인이 만든 스크립트라 안전합니다. 아래쪽 **고급** 클릭 → **(프로젝트 이름)(안전하지 않음)으로 이동** 클릭 → **허용**
10. 배포가 완료되면 **웹앱 URL**이 나옵니다 (`.../exec` 로 끝나는 긴 주소). 이 주소를 복사

이제 다시 GitHub로 돌아가서:

11. 저장소의 **config.js** 파일 클릭 → 연필 아이콘(수정) 클릭
12. 아래 줄을 찾아서:
    ```
    CLICK_LOG_URL: "https://script.google.com/macros/s/여기에_배포된_스크립트_ID/exec",
    ```
    따옴표 안 전체를 방금 복사한 웹앱 URL로 교체
13. **Commit changes** 클릭

이제부터 누군가 사이트에서 식당을 클릭하면, 구글시트 하단에 **"클릭수"** 라는 새 탭이 자동으로 생기고 `식당명 | 클릭수 | 최근 클릭 일시` 가 자동으로 쌓입니다. 이 탭은 시트 주인인 나한테만 보이니 별도 관리자 화면이 필요 없어요.

## 9단계. 방문자수 / 조회수 설정하기 (GA4)

1. **analytics.google.com** 접속 (구글 계정 로그인)
2. 처음이면 계정 만들기 화면이 뜸 → 계정 이름 아무거나 입력 → 다음
3. "속성 만들기" 화면 → 속성 이름 `강릉뭐먹지` 입력 → 시간대 대한민국, 통화 원(KRW) 선택 → 다음
4. 비즈니스 정보 대충 선택하고 **만들기**
5. 데이터 수집 방법 선택 화면에서 **웹** 클릭
6. **웹사이트 URL**에 4단계에서 받은 사이트 주소 입력 (예: `https://내아이디.github.io/gangneung-food-map/`)
7. 스트림 이름 아무거나 입력 → **스트림 만들기**
8. 만들어진 스트림 상세 화면에 **측정 ID** (`G-`로 시작하는 코드)가 보입니다. 복사

이제 다시 GitHub로:

9. **index.html** 파일 클릭 → 연필 아이콘(수정)
10. `G-XXXXXXXXXX` 라는 글자가 **두 군데** 있습니다 (Ctrl+F로 검색). 둘 다 방금 복사한 측정 ID로 교체
11. **Commit changes** 클릭

방문자수/조회수는 analytics.google.com에 다시 로그인해서 왼쪽 메뉴 **보고서 → 실시간** (당장), 또는 **보고서 → 획득** (날짜별 누적)에서 확인할 수 있어요. 로그인해야 보이는 화면이라 방문자에게는 안 보이고 나만 봅니다.

> 참고: GA4는 반영까지 몇 시간 정도 걸릴 수 있어요. 오늘 만들었는데 오늘 숫자가 0이어도 정상입니다.

## 10단계. 최종 점검

사이트 주소(`https://내아이디.github.io/gangneung-food-map/`)에 접속해서 아래를 확인하세요.

- [ ] 지도가 뜨고, 마커가 하나씩 찍히는가
- [ ] 목록에 식당들이 보이는가
- [ ] 검색창에 "막국수" 쳤을 때 관련 식당만 남는가
- [ ] 카테고리 칩(한식/카페 등) 눌렀을 때 필터링되는가
- [ ] 식당 클릭 시 아래에서 상세 정보 시트가 올라오는가
- [ ] (선택) 식당 클릭 후, 구글시트에 "클릭수" 탭이 생기고 숫자가 올라가는가
- [ ] 스마트폰으로 접속했을 때도 레이아웃이 깨지지 않는가

전부 체크되면 런칭 완료입니다. 이 주소를 카카오톡 오픈채팅방, 인스타그램 등에 공유하시면 됩니다.

## 11단계. 내 도메인(www.xxx.com) 연결하기

지금 사이트 주소는 `내아이디.github.io/gangneung-food-map/` 형태인데, `www.강릉맛집.com` 같은 내 도메인으로 바꾸는 방법입니다. "www"만 따로 사는 게 아니라, 본체 도메인(예: `gangneungfood.com`)을 산 뒤 그 앞에 `www.`를 붙여서 씁니다.

### 11-1. 도메인 구매하기

1. 도메인 등록업체 사이트 접속 (택 1)
   - **가비아** (gabia.com) — 한국어, 국내 결제 편함, 초보자에게 추천
   - **후이즈** (whois.co.kr) — 가비아와 비슷
   - **Namecheap** (namecheap.com) — 영어 사이트, 보통 더 저렴함
2. 검색창에 원하는 이름 입력 (예: `gangneungfood`) → `.com`, `.co.kr`, `.kr` 등 사용 가능한 옵션 확인
   - `.com`이 무난합니다. 가격은 보통 연 1만~2만원대
3. 장바구니 담고 결제 (카드결제 가능)
4. 구매 완료되면 "내 도메인 관리" 또는 "My Domain List" 같은 메뉴에서 방금 산 도메인이 보임

### 11-2. DNS 설정하기 (도메인 ↔ GitHub 연결)

도메인을 산 사이트(가비아/후이즈/Namecheap 등)로 돌아가서, **DNS 관리** 또는 **네임서버 관리** 메뉴로 들어갑니다. (업체마다 메뉴 이름이 조금씩 다르지만 보통 "DNS 설정", "DNS 관리툴" 이런 이름입니다)

아래 **레코드 4개**를 추가하세요:

**www 로 접속했을 때 (예: www.gangneungfood.com)**
| 타입 | 호스트/이름 | 값 |
|---|---|---|
| CNAME | `www` | `내아이디.github.io` |

**www 없이 접속했을 때 (예: gangneungfood.com)**
| 타입 | 호스트/이름 | 값 |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |

- `호스트/이름` 칸에 `@`는 업체에 따라 빈칸으로 두거나 도메인 자체를 의미하는 표시로 되어 있을 수 있습니다.
- A 레코드 4개는 GitHub Pages가 고정으로 쓰는 IP 주소라서 그대로 입력하면 됩니다 (내 계정과 무관하게 항상 동일).
- 저장 후 실제로 반영되기까지 **최소 10분 ~ 최대 48시간** 걸릴 수 있어요. (보통 1시간 이내)

### 11-3. GitHub에 커스텀 도메인 등록하기

1. GitHub 저장소 → **Settings** → **Pages**
2. **Custom domain** 입력창에 `www.gangneungfood.com` 입력 (본인이 산 도메인) → **Save**
   - 저장하면 저장소에 `CNAME`이라는 파일이 자동으로 하나 생깁니다. 따로 만들 필요 없어요.
3. DNS가 잘 반영됐다면 잠시 후 같은 화면에 초록색 체크와 함께 **Enforce HTTPS** 체크박스가 활성화됩니다. 이 박스를 꼭 체크하세요 (자물쇠 표시, 보안 접속)
   - 인증서 발급까지 몇 시간 걸릴 수 있습니다. 바로 안 눌러져도 나중에 다시 와서 체크하면 됩니다

### 11-4. 다른 설정들도 새 주소로 갱신하기 (중요, 빼먹기 쉬움)

도메인을 바꾸면 아래 3곳도 **반드시** 새 주소로 다시 등록해야 합니다. 안 하면 지도가 안 뜨거나 방문자 통계가 끊깁니다.

1. **카카오 개발자 콘솔** → 내 애플리케이션 → 플랫폼 → 기존 `내아이디.github.io` 주소는 그대로 두고, `https://www.gangneungfood.com` 을 **추가로** 등록 (지우지 않아도 됩니다)
2. **Google Analytics(GA4)** → 관리 → 데이터 스트림 → 스트림 URL을 새 도메인으로 수정 (또는 스트림을 새로 만들어도 됨)
3. 카카오 계정에 로그인된 상태에서 실제로 `www.gangneungfood.com` 으로 접속해 지도가 뜨는지 확인

### www 없이 짧게(gangneungfood.com)만 쓰고 싶다면?

11-2의 A 레코드만 설정하고, GitHub Custom domain 칸에는 `gangneungfood.com` (www 없이) 입력하면 됩니다. 다만 실무에서는 `www.`가 있는 쪽으로 통일하고, www 없는 주소는 www로 자동 연결(리다이렉트)되게 설정하는 걸 더 권장합니다 — 도메인 구매처의 "URL 포워딩" 또는 "리디렉션" 메뉴에서 설정 가능합니다.

## 문제 해결 (FAQ)

| 증상 | 원인과 해결 |
|---|---|
| 지도 자리가 회색으로 비어있음 | 5단계 카카오 키가 안 들어갔거나, "Web 플랫폼"에 등록한 주소가 실제 사이트 주소와 다름. 주소 끝에 `/`가 있고 없고까지 정확히 맞춰야 함 |
| 목록/지도 아무것도 안 뜸, "데이터를 불러오지 못했습니다" 메시지 | 7단계 구글시트 공유 권한이 "제한됨"으로 되어있음 |
| 목록은 나오는데 마커(핀)가 안 찍힘 | 식당 이름만으로 카카오 장소검색이 안 되는 경우(폐업/이름 변경 등). 큰 문제는 아니고, 소재지를 더 자세히 적으면 나아짐 |
| 클릭수 탭이 안 생김 | 8단계에서 `CLICK_LOG_URL`을 안 바꿨거나, Apps Script 배포 시 "액세스 권한: 모든 사용자"를 선택 안 함 |
| GitHub에 파일 올릴 때 "파일이 너무 크다" 오류 | 이 프로젝트 파일들은 다 작아서 발생 안 함. 혹시 다른 파일을 잘못 올린 건 아닌지 확인 |
| 파일을 잘못 고쳤어요, 되돌리고 싶어요 | 해당 파일 페이지에서 **History** (파일 목록 오른쪽 위 시계 아이콘) 클릭 → 이전 버전 클릭 → 그 내용 복사해서 다시 덮어쓰기 |

막히는 단계가 있으면 몇 단계에서 어떤 화면이 나오는지 말씀해주세요. 그 부분만 더 자세히 풀어드릴게요.
